# GREEN ALERT – Website cảnh báo môi trường

Dự án demo Nhóm 7 – Đề tài 31: Ứng dụng cảnh báo môi trường (ô nhiễm, rác thải).

## Chạy trên máy tính
Mở file `index.html` bằng Chrome/Edge/Safari.

## Chạy trên điện thoại
Có thể mở website sau khi đưa thư mục lên GitHub Pages hoặc một hosting tĩnh.

## Chức năng demo
- Trang chủ
- Cảnh báo môi trường và bộ lọc
- Bản đồ mô phỏng
- Gửi báo cáo, tự thêm báo cáo vào bảng quản trị
- Kiến thức môi trường
- Dashboard quản trị
- Responsive cho máy tính và điện thoại

Lưu ý: Đây là bản demo front-end, dữ liệu chưa lưu vào cơ sở dữ liệu thật.
